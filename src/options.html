欢迎使用

三步开始阅读

  1. 1填入你的 API Key，保存设置。
  2. 2回到论文页面，选中一段文字或一个公式。
  3. 3点击浮出的「翻译」或「解释」；也可用右键菜单和快捷键。
还差一步：填写 API Key 后即可开始使用。密钥只保存在本机浏览器中。
01

连接模型

兼容 OpenAI Chat Completions 接口。默认使用 DeepSeek。

若接口完整地址以 /chat/completions 结尾，也可以直接粘贴完整地址。
存储于 chrome.storage.local，不会上传到 ScholarLens 的任何服务器。本地服务可留空。

PRIVACY

数据如何流动

  • 选中的文字与公式在页面内提取。
  • 点击处理时，只把当前选区发送到你配置的模型接口。
  • API Key 与偏好设置保存在本机浏览器。
  • 没有 ScholarLens 中转服务器，也没有统计埋点。

请遵守你所在机构对论文内容与第三方 API 的使用规定。

∑

公式识别提示网页使用 MathML、KaTeX、MathJax 或文本中的 LaTeX 时效果最好；纯图片公式会读取图片的 alt 文本。
