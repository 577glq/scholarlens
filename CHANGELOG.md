# Changelog

## Browser extension 0.4.0

- Added an **Interface language** setting: Auto, English, or Chinese.
- Localized the settings page, selection panel, popup, and PDF reader.
- English metadata and English README screenshots.
- Fixed the tab labels and popup placeholder when switching to English.

## Browser extension 0.3.0

- Added the ScholarLens PDF reader start screen with local file selection and drag-and-drop.
- Added online PDF URL loading.
- Translate selections in the reader with `Alt+T`.
- Added an always-visible **Open PDF reader** entry in the popup.

## Browser extension 0.2.0

- Added the PDF.js reader and online PDF support.
- Added the `Alt+T` selection shortcut.
- The toolbar popup detects online PDFs and offers **Open reader**.

## Browser extension 0.1.1

- Added the PDF / clipboard translation popup.
- Moved settings to the gear button.

## Browser extension 0.1.0

- Web selection translation and explanation.
- Formula protection for MathML, KaTeX, MathJax, MediaWiki, image alt text, and LaTeX.
- KaTeX rendering, formula reference, missing-formula warnings, and Markdown copy.
- OpenAI-compatible API with DeepSeek as the default.

## Zotero plugin 0.1.4

- Zotero 7+ selection popup translation/explanation.
- Streaming output, formula protection, KaTeX rendering, settings, and connection test.
