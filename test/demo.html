Scaling Laws for Neural Language Models

Alex Rivera, Mei Chen, Jonathan Park
Institute for Foundation Models

Abstract We study empirical scaling laws for language model performance on the cross-entropy loss. We find that the loss scales as a power-law with model size, dataset size, and the amount of compute used for training, with trends spanning more than seven orders of magnitude.

2. Empirical scaling laws

We study the test loss of autoregressive language models trained on WebText2. Let L(N,D) = (NcN)αN + (DcD)αD L(N,D) = \left(\frac{N_c}{N}\right)^{\alpha_N} + \left(\frac{D_c}{D}\right)^{\alpha_D} L(N,D) = (Nc/N)αN + (Dc/D)αD denote the test loss for a model with N N parameters and D D training tokens. The quantities Nc, DcNc,Dc are characteristic scales, while the exponents αNαN and αDαD control how quickly the loss falls with scale. Under an optimal compute allocation, the empirical frontier follows L(N,D) ≈ L∞ + aN−αN + bD−αD. We observe that these exponents vary only weakly across architecture families, which suggests that scale alone explains much of the reported variance [12, 19].

L(N,D) = L∞ + aN−αN + bD−αD L(N,D) = L_\infty + aN^{-\alpha_N} + bD^{-\alpha_D}

The fitted exponents are αN ≈ 0.076 and αD ≈ 0.095. These estimates imply that increasing model size by 10× reduces the irreducible loss by roughly 10−αN, holding the data budget fixed. The relationship is not a theorem about all architectures; it is an empirical regularity within the measured range.

A natural question is whether compute-optimal training simply maximizes N for a fixed budget. The data indicate otherwise: once D becomes too small, additional parameters yield diminishing returns, and the two terms in the loss trade off against one another. This is why the fitted frontier in Eq. (2) must be reported together with the data regime in which it was measured.
